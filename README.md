# Portfólio Pessoal

Este é meu portfólio pessoal desenvolvido com React e Vite. Aqui você encontrará informações sobre mim, meus projetos, habilidades e formas de contato.

## 🚀 Tecnologias Utilizadas

- React
- Vite
- CSS Modules
- React Router
- Framer Motion (para animações)
- React Icons

## 📋 Funcionalidades

- Design responsivo
- Animações suaves
- Seções interativas
- Modo claro/escuro
- Formulário de contato
- Galeria de projetos
- Blog integrado

## 🛠️ Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/JoaoSantosCodes/portfolio.git
```

2. Instale as dependências:
```bash
cd portfolio
npm install
```

3. Execute o projeto:
```bash
npm run dev
```

4. Acesse `http://localhost:5173` no seu navegador

## 📦 Build

Para criar uma versão de produção:

```bash
npm run build
```

## 🌐 Deploy

O site está hospedado no GitHub Pages e pode ser acessado em: [https://joaosantoscodes.github.io/portfolio](https://joaosantoscodes.github.io/portfolio)
